# Phasmophobia Cheat Sheet Web App

An updated, interactive cheat sheet and guide for the game Phasmophobia.  
Features latest maps, ghost info, evidence, and strategies, tailored to the newest game update.

**Features**
- Map gallery
- Ghost/evidence/item tracker
- Up-to-date game data
- Responsive design

**How to use**
1. Select a map to view details and images.
2. Track ghost evidence and narrow down suspects.
3. Reference strategies and mechanics updated for the latest version.

**Map Images**
All map images are sourced from public, community-friendly resources. If you wish to contribute updated images, submit a PR!

---

**Setup**
```bash
npm install
npm start
```
